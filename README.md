## How to Run
- In a terminal run the .jar file in the back end to boot up SpringBoot
- Now that the server is running, boot Andriod Studio.
- Now that Android Studio is running, set up an emulated device to play the app on.
- Once set up go Run the aoo,
- Know how to run the app in many spaces.
